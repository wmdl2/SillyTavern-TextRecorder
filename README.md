# 文本记录器 (SillyTavern Text Recorder)

这是一个专为 SillyTavern 设计的轻量级 UI 插件。它在你的酒馆内提供了一个悬浮的“文本记录本”，非常适合用来随时保存 API 密钥、角色灵感、跑团设定以及临时笔记。经过多次深度交互优化，现在的它不仅美观，而且像真正的桌面级编辑器一样顺滑！

## 🌟 核心特色功能

- 🗂️ **嵌套分类**：像电脑文件夹一样，支持创建无限层级的文件夹和文本，让你的笔记井井有条。
- 🖱️ **沉浸式行内操作 (Inline Editing)**：
  - 鼠标**悬停**在任意文件夹上，右侧会自动浮现专属的“新建文本 (➕📄)”和“新建文件夹 (➕📁)”按钮。
  - **行内新建与重命名**：抛弃丑陋的网页弹窗！双击文本或点击编辑按钮，直接在列表内打字并回车保存。
  - **一键删除**：悬停时出现红色垃圾桶，直观且防误触。
- 📉 **迷你悬浮球模式**：点击窗口右上角的 `-` 按钮，整个庞大的面板会**瞬间收缩成一个圆形的“书本”悬浮小球**。它可以被随意拖拽到屏幕任何角落，想用时点一下即可展开，完全不遮挡角色对话！
- 🎨 **多重主题色 (Theming)**：在设置面板中内置了 7 款精美主题（默认、纯黑、深蓝、墨绿、琥珀、明亮、暖色、浅灰蓝），可一键切换，完美适配不同风格的酒馆主题。
- ⚡ **双重呼出方式**：可以通过魔法棒菜单呼出，也可以直接在聊天框输入 `/recorder` 呼出！
- 📝 **快捷编辑器**：右侧编辑区自带一键复制、粘贴、清空和保存功能，支持随时拖动边框改变大小。

## 📦 如何安装？

1. 复制本 GitHub 仓库的网址。
2. 打开你的 SillyTavern。
3. 点击顶部的 **扩展（Extensions，积木图标）** 菜单。
4. 点击 **Install Extension (安装扩展)** 按钮，将刚才复制的网址粘贴进去。
5. 点击 **Install (安装)**。
6. 刷新你的 SillyTavern 网页即可。

## 🎮 如何使用？

1. **打开插件**：
   - 方法一：在聊天输入框打出 `/recorder` 并回车。
   - 方法二：点击酒馆左下角的 **魔法棒** 图标，在弹出的菜单中点击 **文本记录器**。
2. **管理文件**：
   - 鼠标悬停在文件夹上，使用右侧快捷图标进行新建。
   - 双击文件/文件夹，或者点击右侧的铅笔图标即可重命名。
   - 选中一个文本后，在右侧大文本框内编辑。
3. **保存数据**：
   - 编辑完成后，**务必要点击右上角的“保存（软盘图标）”按钮**，否则刷新网页后未保存的文字会丢失。
4. **个性化配置**：
   - 点击顶部的扩展（积木图标）菜单，找到“文本记录器设置”，在这里可以随时**切换主题颜色**或**彻底停用插件**。

## 💾 数据存储位置

你所有的记录数据都安全地存储在你本地服务器的 SillyTavern 文件夹内，绝不上传云端。具体路径为：
`data/default-user/extension_settings.json`
